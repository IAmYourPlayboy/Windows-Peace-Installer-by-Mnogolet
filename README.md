# Windows Peace

Развёртывание кастомной Windows 11 с флешки за один проход: выбрал диск в нормальном интерфейсе — получил настроенную систему с Atlas и Windhawk без участия человека.

Заменяет ручную процедуру примерно на три часа, включающую двойную установку Windows и физическое отключение лишних дисков.

## Состояние

Шаг А сделан. Приложение под обычную Windows показывает настоящие диски и разделы машины, даёт выбрать цель установки и показывает предпросмотр разметки. Ни одной операции записи оно не выполняет — это осознанно: сначала должно стать видно, правильно ли инструмент понимает железо.

Проверено на живой машине: [запись приёмки](docs/superpowers/notes/2026-08-11-step-a-acceptance.md).

Дальше — шаг Б: тот же мастер, запущенный из WinPE.

## Что решается

Windows Setup принимает два решения самостоятельно и оба — неправильно:

- **Куда ставить.** `DiskID` в `autounattend.xml` — порядковый номер перечисления, а не идентификатор диска. Он меняется между загрузками.
- **Откуда грузиться.** Setup пишет загрузчик в первый найденный EFI-раздел и не трогает порядок загрузки в NVRAM. Отсюда классическое «поставил Windows 11, загрузилась прежняя Windows 10».

Windows Peace не использует `setup.exe`. Разметка, применение образа, загрузчик и записи прошивки — под собственным контролем.

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## Устройство

| | |
|---|---|
| `contract/` | `recipe.schema.json` — единый декларативный контракт |
| `src/WindowsPeace.Studio` | Конструктор рецепта и запись USB, на обычной Windows |
| `src/WindowsPeace.Setup` | Выбор диска и развёртывание, в WinPE |
| `src/WindowsPeace.Agent` | Доводка системы после установки, переживает перезагрузки |
| `src/WindowsPeace.Core` | Модель рецепта, движок шагов, логирование |
| `build/` | Сборка `boot.wim`, запись носителя |
| `test/` | Стенд Hyper-V, E2E-сценарии |

Конфигурация целиком живёт в рецепте. Новый профиль установки — новый JSON, а не правка кода.

Пример: [contract/examples/atlas-25h2-ru.recipe.json](contract/examples/atlas-25h2-ru.recipe.json)

## Границы

- Windows 11 Pro / Pro for Workstations / Enterprise. Home не поддерживается — на нём не ставится Atlas.
- Только UEFI + GPT.
- ISO Windows и плейбук Atlas не распространяются вместе с инструментом, а скачиваются с официальных источников с проверкой SHA256. Лицензия Windows — на стороне пользователя.
- Полностью автоматический Atlas не гарантируется: у AME Wizard нет документированного интерфейса командной строки.
